# 第 1 层（对接桥接的那一层）— 收益与刀法账本

> **用法**：每把刀一行；"可复用思路"给后面的层查。**口径必须标清**：`腿级(串行 NR_RUN_TIMING)` ≠ `region(TU)` ≠ `帧(cgraph 出货配对)`（军规 112/131）。

## 一、这一层的定义与达标状态
- **定义（用户钉死）**：**不是桥接层本身**，是**对接桥接层的那一层** ⇒ `xmx_rec_pre`（读 colour/motion/history/plan/table）与 `xmx_rec_ffn_stem`（写 features 面）。**不许动桥接层。**
- **实测范围**：**4 次设备提交、0 次 memcpy/memset**；桥接面 `id1 colour 2,088,960` / `id3 motion 4,177,920` / `id6 history 6,266,880` / `id4 plan 6,272,916` / `id5 table 262,160`；唯一读者 `xmx_rec_pre` ⇒ 写 `id1271 features 16,711,680`（唯一消费者 `xmx_rec_ffn_stem`）。
- **达标结论（§124）**：**六条线在各自口径下全过** ⇒ **第 1 层结题**；**残留盲区**：`s6_ffn_block_kernel.hpp`（哈希钉死、发射不计数）、`qr_launch_esimd` 的 `launches=0`、`window_block/ffn_block` 发射计数（后者已修，见第 2 层）。

## 二、这一层做过的刀（全部逐位相同）
| # | 刀 | 机制 | 读数（标口径）| 状态 |
|---|---|---|---|---|
| 1 | **`pre` 族 `cr_mul/cr_add/cr_div` 本地遮蔽** | libdevice 正确舍入包装在设备上是 **IMF 软件序列**（`pre` 一核 **37,023 条 GEN**，`cmp 3,966 / shl 1,512 / and 1,508 / shr 1,109`）⇒ 换普通 `* + /`（`contract(off)` 区间内）| **腿级 −93%**，但 **帧 −0.003 ms** ⇒ **非关键路径被 cgraph 重叠吸收** | **保留**（无害）；**教训成为"排刀第一判据"** |
| 2 | **`NR_CHIP_LW16`（chip 路 LW 16）** | 每核宽度折扣 | 帧 −0.2 量级，**单独转正时帧中性**，与 smax 刀合并后兑现 | **已折进默认 ON** |
| 3 | **`ffn_stem` 的 scratch 认知** | 单发 `scr = 116,981,760 B`（该发实际搬 ≈300 MB，而旧 `[hop]` 只报 83.6 MB）| 全帧 `scr = 1.50 GB/帧` | **不是刀，是账**（军规 128）|

## 三、可复用思路（给第 2/3 层）
1. **先问"这条腿在不在关键路径"，再问"码代降了多少"**——本案最强的反例就是 `pre`：腿级 −93% ⇒ 帧 −0.003 ms（军规 131）。
2. **libdevice 包装 = 一次 call + 一条共享 fixup 大树；普通算符 = 每站点内联展开**——**ops 计数与收益没有固定符号关系**（军规 137）。
3. **等价性必须先按操作数类穷举再换**（军规 136）：`fmul_rn/fadd_rn ≡ * /+`（非 NaN 全域）；**`fdiv_rn ≠ /`（11 类，全是产生 NaN 的那些）**。
4. **仪表改动只能放在 launch helper 入口**，绝不能在发射点外加语句/括号（军规 132：**+7 µs/发 × 690 = +4.9 ms/帧**）。
5. **认证一律 cold（当场新建空 `SYCL_CACHE_DIR`）+ 串行 + 带 `[gate-selfcheck]`（写明加载件路径与 md5）+ 标明口径段**（军规 141/146/147/148/150）。
6. **f32→f16 残差流面（省 267.4 MB/帧 ⇒ 0.78 ms@343 GB/s / 0.48 ms@560）**：**用户当年判"不是根本的东西"，但 2026-11-07 已放开画质门 ⇒ 这一条重新可用，排在能改数值的刀之后**。
