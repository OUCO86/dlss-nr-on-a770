## 3. 白名单建议（40dB / 35dB 两档）
- **≥40 dB：空集。** 测到的最好点 = 跳 1 条 C512 链 = 30.91 dB（−0.22 ms）。
  门槛在 40 dB 以上的任何跳块，本判官下都不存在。
- **≥35 dB：空集。** 同上（30.91 < 35）。
- 若按"与跳 1 条同 dB 档"取边际免费区（= 30-31 dB 平台）：
  **C512all = 链 18,19,20,21,22,23,24,26,27,28,29,30,31,32（14 条）= −4.69 ms，30.80 dB，
  worst-1% 23.93 dB，两进程 md5 全同（不闪）** ⇒ 这是今晚唯一能给的"可用跳表"，
  但它落在 lmxx 记的 33-35 dB"NR 等于没开"区间之下 ⇒ **按军规必须实机画面验收**。
- 平台的边界（第四轮实测）：**mix16 = C512all + 链 10,11（两条 C256）= −5.60 ms @ 30.06 dB**
  ⇒ 比 C512all 多花 0.74 dB 换到再多 0.91 ms；再加解码器 C128 就掉出平台：
  **mix17 = C512all + 42,43,46 = −6.50 ms @ 26.68 dB**。
- 再往下的组合都不划算：C256all 单独 = 24.17 dB；big28（C512+C256 全跳）= 21.94 dB / −9.79 ms
  ⇒ 已进入"糊"区，不建议出货。
- lmxx 的 42,43,46 语义映射到我们 = 链 42,43,46（解码器 C128 后段）= −1.36 ms @ 27.22 dB
  ⇒ 同样 <35 dB，**不能照抄**（我们的 1301 面对结构改动放大得比 lmxx 的 [0,1] 画面狠）。

## 4. 诚实上限（71 层模型，只靠跳块）
- 单价表加和（44 条可跳链，按各档全跳单价）：−19.67 ms ⇒ 理论 43.65 ms
- **实测 all44（44 条全跳）= 43.98 ms（−19.35 ms）**，dB = 16.96 / worst-1% 10.59
  ⇒ "只靠跳块"的物理上限 ≈ **44 ms/帧 @ 960×544**，且这个上限本身已经是
  "NR 等于没开"级别（比 notes 里 e4m3 扰动穿 120 层残差链的 17 dB 地板还差一点点）
- 在 ≥35 dB（更不用说 ≥40 dB）约束下，跳块能给的量 = **0 ms**；
  在"与单链同 dB 平台"（30-31 dB）约束下 = **−4.7…−5.6 ms（63.3 → 58.6 / 57.7 ms）**
  （C512all 30.80 dB；mix16 30.06 dB）
- ⇒ 跳块不是通往 20 ms 的路：它最多把 63 ms 抬到 58.6 ms（可辩护档）或 44 ms（不可辩护档）。
  20 ms 仍要靠 S6 驻留/融合把链环节数打下来，不是靠砍块。
